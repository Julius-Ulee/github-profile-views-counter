## [🚀 GitHub Profile Views Counter](https://github.com/gayanvoice/github-profile-views-counter)
**GitHub Profile Views Counter** es un proyecto de código abierto impulsado enteramente por `GitHub Actions` para obtener y almacenar estadísticas de repositorios.
Utiliza la `GitHub API` para obtener los datos de estadísticas de tus repositorios y realiza commits de los cambios en un repositorio separado.

El proyecto fue creado y es mantenido por [gayanvoice](https://github.com/gayanvoice). No olvides seguirlo en [GitHub](https://github.com/gayanvoice), [Twitter](https://twitter.com/gayanvoice) y [Medium](https://gayanvoice.medium.com/).

## ⛔ NO HACER
- No realices commit de ningún cambio en el directorio `./cache`. Esta función ayuda a mantener la integridad de los registros de los visitantes.
- La aplicación dejará de medir las estadísticas automáticamente hasta que reviertas esos commits.
